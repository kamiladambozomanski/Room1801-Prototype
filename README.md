# Room 1801 :: Prototype

**Unreal Engine 5 · University Project · Early Prototype**

An early prototype developed as part of the development of [Room 1801]([https://github.com/kamiladambozomanski/Room1801](https://kamil-adam-bozomanski.itch.io/room-1801)), a local-multiplayer psychological horror game created at the University of South Wales.

This repository contains an earlier version of the project, preserved for reference and portfolio purposes.

## Project Status

This is an **experimental university prototype**, not a finished or fully functional game. Its primary purpose was to explore the game's visual direction and establish an early foundation for development.

The project was subsequently developed further in the main [Room 1801 repository](https://github.com/kamiladambozomanski/Room1801).

## Technical Details

- **Engine:** Unreal Engine 5
- **Status:** Archived prototype
